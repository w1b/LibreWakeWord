# Model and runtime artifact roadmap

LibreWakeWord does not have permission to redistribute vendor wake-word models or Google SODA runtime binaries. The copies currently present in this private development tree are temporary test fixtures and must not be present in a public release.

Before publication, this document will be replaced by:

- a guide for extracting a compatible DSP model from a device or software distribution where the user is entitled to access it;
- a guide for extracting the matching second-stage model and temporary SODA runtime for personal interoperability work; and
- documentation for the planned freely redistributable second-stage runtime reimplementation.

Those guides must identify supported versions, verify hashes and metadata, avoid distributing the artifacts themselves, and clearly separate interoperability instructions from project code.
